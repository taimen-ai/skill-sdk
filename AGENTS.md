# Соглашения для исполнителя: skill-sdk

Этот файл читают кодовые агенты и люди, которые меняют репозиторий. `CLAUDE.md`
ссылается сюда же; машиночитаемая часть (соседи, установка, проверки) —
[`.agents/runner.yaml`](.agents/runner.yaml). Что делает библиотека — в
[README.ru.md](README.ru.md).

## Раскладка

- `src/skill_sdk/` — библиотека: декоратор `@skill` и контракт v1 (`skill.py`,
  `core.py`), контекст вызова (`context.py`), хостинг `local`/`http`/`mcp`
  (`http.py`, `mcp.py`, `auth.py`), экспорт в пакет каталога (`package.py`,
  `cli.py`), подделки для тестов скиллов (`testing.py`).
- `tests/` — тесты; `tests/sample_skills.py` — скиллы-образцы для них.
- Соседи в `sdk/` суперпроекта (раскладка TAI-ADR-0064, сам skill-sdk —
  `sdk/skill-sdk`): `../platform-auth-sdk` (экстры `http`, `mcp`) и
  `../platform-llm` (экстра `llm`) — path-зависимости из `pyproject.toml`. Они
  стоят на ревизиях, закреплённых суперпроектом, и доступны **только для
  чтения**: правка соседа — отдельная задача в его репозитории.

## Сборка и проверки

Проект — [uv](https://docs.astral.sh/uv/), Python 3.12. Всё, что зовёт CI, —
цели `make`:

```bash
make install     # uv sync --frozen --all-extras
make lint        # ruff check + ruff format --check
make typecheck   # mypy (strict)
make test        # pytest со всеми экстрами
make check       # всё перечисленное подряд
```

`make test-e2e` — скилл SDK сквозь настоящий исполнитель ядра по всем трём
протоколам. Он идёт в окружении ядра (`../../services/control-plane`, каталог
переопределяется `CONTROL_PLANE_DIR`). Прогоняй его, если меняешь хостинг,
контекст вызова или то, что видит исполнитель; без ядра рядом тест пропускается.

Тестам не нужны ни база, ни Docker, ни сеть.

## Перед сдачей

- `make check` зелёный. Тесты — последовательно, один прогон за раз.
- Меняешь поведение — тест в том же коммите.
- Меняешь публичный контракт (декоратор, контекст, хостинг, формат экспорта) —
  обнови `README.md` и `README.ru.md` вместе.
- Меняешь зависимости — `uv.lock` в том же коммите; `THIRD_PARTY.md` и
  `sbom.json` пересобираются по `CONTRIBUTING.md`.

## Правила

- Опубликованная версия скилла неизменяема: изменение контракта — новая
  `version` в декораторе, а не правка старой.
- Компонент нейтрален к продукту (white-label): имя продукта не появляется в
  именах кода, переменных, маршрутах и сообщениях. Исключения — документы
  проекта о себе (`NOTICE`, `TRADEMARK.md`, `CONTRIBUTING.md`, `SECURITY.md`) и
  имена репозиториев.
- Документация — на русском, `README.md` — на английском; имена API и сущностей —
  на английском. Комментарии в коде — как в окружающем коде.
- Не коммить секреты, `.env`, абсолютные локальные пути, внутренние адреса и
  артефакты сборки (`.venv/`, кэши).
- Не трогай `main` и чужие ветки.
- Не делай того, чего нет в задаче: найденное попутно — в отчёт, а не в код.
